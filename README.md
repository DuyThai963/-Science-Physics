# Science - Physics (Dual Data Stream Platform)

Nền tảng lưu trữ và quan sát tư liệu phân tán hai nguồn, thiết kế theo phong cách **Monochrome Minimalist (Đen - Trắng - Xám)**:
1. **Engine VSPHIM**: `https://nguon.vsphim.com/api`
2. **Engine TOPXX**: `https://topxx.vip/api/v1`

---

## 🚀 Tính Năng Chính
- **Bộ Lọc Nâng Cao Đa Nguồn:**
  - VSPHIM: Lọc theo Thể loại, Quốc gia, Năm phát hành.
  - TOPXX: Lọc Phim hôm nay (`/movies/today`), Thể loại, Quốc gia.
- **Thanh Chủ Đề Tối Ưu:** Top 8 thể loại nổi bật + Modal tìm kiếm nhanh tất cả chủ đề, hỗ trợ cuộn chuột ngang và kéo thả chuột.
- **Trình Phát Native Mượt Mà:** Xem trực tiếp qua iframe ổn định, hỗ trợ Tắt sáng tập trung (Lights Off) và Mở rộng rạp hát (Theater Mode).
- **Giao Diện Mobile Hoàn Thiện:** Sub-bar cố định đổi nguồn `VSPHIM / TOPXX` ngay dưới header, thao tác thuận tiện bằng 1 tay.
- **Chế Độ Ngụy Trang (Boss Key):** Bấm phím `Esc` để hiển thị bài báo nghiên cứu Vật Lý Lượng Tử (Quantum Field Theory).

---

## ⚡ Hướng Dẫn Khởi Động

### Cách 1: Chế độ Dev (Live reload)
Nhấp đúp chuột vào file **`dev.bat`**.
- Khởi động Backend API tại `http://127.0.0.1:5001` và Frontend Vite tại `http://127.0.0.1:3000`.
- Mở trình duyệt truy cập: **`http://localhost:3000`**

### Cách 2: Chạy trực tiếp (Server sản xuất)
Nhấp đúp chuột vào file **`start.bat`**.
- Mở trình duyệt truy cập: **`http://localhost:5001`**
